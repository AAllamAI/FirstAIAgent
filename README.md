# Chatbot بسيط - مشروع تعليمي

## خطوات التشغيل

### 1. ثبّت المكتبة المطلوبة
```bash
pip install -r requirements.txt
```

### 2. احصل على API Key
- روح على https://console.anthropic.com
- سجّل حساب (فيه رصيد مجاني للبداية)
- اعمل API key جديد من صفحة "API Keys"

### 3. حط الـ API key في ملف `.env`
اعمل ملف اسمه `.env` (بالظبط بالاسم ده، من غير امتداد) في نفس مجلد المشروع،
وحط فيه سطر واحد بمفتاحك الحقيقي (شوف `.env.example` كمثال):

```
ANTHROPIC_API_KEY=sk-ant-api03-...
```

⚠️ **مهم:** متشاركش الملف ده مع حد ولا ترفعه على GitHub — فيه مفتاحك الخاص.

### 4. شغّل البرنامج
```bash
python chatbot.py
```

---

## إيه اللي هتتعلمه من الكود ده؟

| المفهوم | فين في الكود |
|---|---|
| الاتصال بالـ API | `anthropic.Anthropic(api_key=...)` |
| conversation history | الـ list اسمها `conversation_history` |
| Streaming responses | `client.messages.stream(...)` |
| System prompt | الـ parameter `system=` |
| Error handling | الـ `try/except` block |

## تحديات لما تخلص (جرب تضيفهم بنفسك)

1. **سهل:** خلي الموديل يفتكر اسمك لو قلته له
2. **متوسط:** اعمل خاصية تحفظ المحادثة في ملف عشان لو قفلت البرنامج ورجعت تفتحه تلاقي المحادثة موجودة
3. **متوسط:** ضيف حد أقصى لعدد الرسائل المحفوظة (مثلاً آخر 10 بس) عشان توفر تكلفة الـ API
4. **صعب:** حوّل المشروع لـ web app بسيط باستخدام Streamlit بدل التيرمنال

كل تحدي من دول هيوصلك خطوة أقرب لمشروع الـ RAG اللي هنعمله بعد كده.
